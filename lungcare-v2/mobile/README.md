# LungCare Mobile PWA

## Cài trên điện thoại

1. Mở đường dẫn mobile preview bằng Chrome/Safari.
2. Chọn **Thêm vào màn hình chính / Add to Home Screen**.
3. Mở trên 3 điện thoại và chọn 3 role demo: Người bệnh, Điều dưỡng, Bác sĩ.
4. Đây là demo offline/local snapshot; chưa có realtime backend và không dùng dữ liệu bệnh nhân thật.

## Luồng demo

Người bệnh → Gửi khai bệnh → Điều dưỡng/Bác sĩ đọc báo cáo → phân loại KHẨN/CẦN XEM HÔM NAY/ỔN ĐỊNH → mở clinical review.
